# CS-360
CS 360 Mobile Architect & Programming Portfolio Reflection
App Overview

The goal of my mobile application was to provide users with a simple and efficient way to manage inventory items through a mobile device. The application allows users to create, update, view, and delete inventory records while maintaining secure access through a user login system. The app was designed to address the need for a convenient inventory management solution that enables users to organize and track information from anywhere. By combining data management with mobile accessibility, the application provides a practical tool that supports productivity and organization.

User-Centered Design

Several screens and features were necessary to support user needs and create a user-centered experience. The application included a login screen for secure authentication, an inventory display screen for viewing stored items, and screens that supported adding, editing, and deleting inventory records. Optional SMS notification functionality was also considered to provide users with reminders and updates.

My UI designs focused on simplicity, clarity, and ease of navigation. I organized information logically and reduced unnecessary complexity so users could quickly complete common tasks. Buttons, menus, and input fields were positioned to support intuitive interaction. These design decisions were successful because they prioritized usability and allowed users to accomplish their goals efficiently with minimal confusion.

Development Process

When developing the application, I approached the project incrementally by building one feature at a time and testing functionality as I progressed. I began by reviewing requirements and UI designs before implementing database functionality, user authentication, inventory management features, and application navigation.

I used modular development techniques by separating functionality into manageable components and methods. Debugging tools, emulator testing, and code reviews were also important parts of my strategy. These approaches can be applied to future projects because they improve organization, simplify troubleshooting, and make applications easier to maintain and expand over time.

Testing and Quality Assurance

To ensure the application functioned correctly, I performed frequent testing throughout development using the Android emulator and application logs. I tested user authentication, database operations, inventory creation, inventory updates, inventory deletion, and overall navigation between screens. I also verified that the application handled user input correctly and that data was stored and retrieved as expected.

Testing is important because it identifies errors before deployment and helps ensure the application provides a reliable user experience. Through testing, I discovered issues related to database interactions, user input handling, and application flow. Identifying these issues early allowed me to make corrections and improve the overall quality of the app.

Innovation and Problem Solving

One of the greatest challenges during development was integrating multiple components into a single functional mobile application. User authentication, database connectivity, inventory management, and navigation all had to work together seamlessly. To overcome this challenge, I carefully reviewed requirements, broke problems into smaller tasks, and implemented solutions incrementally.

I also had to ensure that the user interface remained simple while still supporting all required functionality. This required balancing technical requirements with user experience considerations. By continuously testing and refining the application, I was able to develop a solution that met project objectives while maintaining usability.

Demonstration of Knowledge and Skills

The component of the application that best demonstrates my knowledge, skills, and experience is the inventory management functionality integrated with the SQLite database. This feature required implementing create, read, update, and delete (CRUD) operations while maintaining a responsive user interface and reliable data storage.

Successfully connecting the frontend user interface with backend data management demonstrated my ability to apply programming concepts, database management techniques, debugging skills, and user-centered design principles. This portion of the project reflects the technical growth I achieved throughout the course and represents a strong example of my ability to develop practical mobile applications.

Reflection

This project provided valuable experience with the complete mobile application development lifecycle, from planning and design to coding, testing, and refinement. Throughout the course, I strengthened my skills in Android development, database management, UI design, debugging, and software testing. I also gained a better understanding of how user needs drive design and development decisions.

Completing this project increased my confidence in developing mobile applications and provided a strong portfolio artifact that showcases both technical and problem-solving abilities. The knowledge and experience gained from this course will help me continue growing as a software developer and support my long-term career goals in software engineering and application development.
